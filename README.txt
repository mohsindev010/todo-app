MY TO-DO APP — NODE.JS + EXPRESS + HTML/CSS/JAVASCRIPT

1. Extract the ZIP file.
2. Open the extracted todo-app folder in VS Code.
3. Open Terminal > New Terminal. Ensure terminal is in the todo-app folder.
4. Install Express:
   npm.cmd install
   (Use npm.cmd in PowerShell to avoid the npm.ps1 script policy issue.)
5. Start the server:
   npm.cmd start
   Or run: node server.js
6. Open http://localhost:3000 in your browser.

Keep the terminal open while using the app. Tasks are stored in memory and reset
when the server restarts. Do not open public/index.html directly; use localhost.
